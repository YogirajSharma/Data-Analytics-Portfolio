# Honda Bike Sales Dashboard – Excel

## Project Overview

This project presents an interactive Excel dashboard for analyzing customer demographics and bike purchase behavior.

The dashboard provides insights into customer count, bike purchases, income, age groups, occupation, education, gender, commute distance, and purchase decisions.

## Dashboard Analysis

The dashboard covers the following areas:

- Customer Count
- Total Bike Purchases
- Average Income
- Age Group-wise Bike Purchase Decision
- Occupation & Home Ownership-wise Average Income
- Education-wise Customer Distribution
- Gender-wise Average Income by Purchase Decision
- Commute Distance-wise Bike Purchase Decision
- Region-wise Analysis
- Marital Status Analysis
- Cars Owned Analysis
