This folder contains my **Excel Data Analytics projects**, developed to demonstrate practical skills in data analysis, dashboard development, business reporting, and data visualization.

These projects showcase how Microsoft Excel can be used to transform raw data into interactive dashboards and meaningful business insights.

### 💡 Skills Demonstrated

- 📉 Trend Analysis

An interactive Excel dashboard designed to analyze subscription activity, payment status, new subscriptions, and cancellation trends.

- New Subscriptions by Month
- Subscription Cancellations Over Time
- Year-wise Subscription Analysis
