# Amazon Sales Dashboard – Excel

## Project Overview

This project presents an interactive Excel dashboard for analyzing Amazon sales performance, sales distribution, and key performance indicators.

The dashboard provides insights into sales performance across salespeople, products, shipping modes, states, cities, customer segments, and customers.

## Dashboard Sections

### 1. Sales People Dashboard

This dashboard analyzes:

- Salesperson-wise total sales
- Sales target
- Achievement percentage
- Missed percentage
- Individual salesperson performance

### 2. Sales Dashboard

This dashboard analyzes:

- Ship mode-wise orders
- Average shipping time
- Product category-wise sales
- Product category-wise profit
- Most profitable product
- Least profitable product

### 3. Distribution Dashboard

This dashboard analyzes:

- State-wise sales
- Customer-wise sales
- Customer segment-wise sales
- Customer-wise order numbers
- Highest-sales state
- Highest-sales city
