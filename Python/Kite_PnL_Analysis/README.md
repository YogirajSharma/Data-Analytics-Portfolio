
# 📊 Kite PnL Analysis Using Python

**An End-to-End Python Data Analytics Project for Intraday Trading Charges and Profit & Loss Analysis**

---

## 📌 Project Overview

The **Kite PnL Analysis Using Python** project focuses on analyzing intraday stock trading transactions to calculate applicable trading charges and determine the actual profitability of each stock.

Using Python and its data analysis libraries, this project processes raw trading order data, calculates transaction charges based on Zerodha's Equity Intraday (NSE) brokerage structure, and generates a comprehensive Excel report.

The final report provides three levels of analysis:

1. **Individual Trade Charges:** Detailed transaction-wise charge calculations.
2. **Stock-wise and Type-wise Analysis:** Aggregated Buy/Sell analysis for each stock.
3. **Overall Stock Summary:** Gross PnL, total charges, Net PnL, and the impact of charges on profitability.

The primary objective is to understand how brokerage and statutory transaction charges affect the actual profitability of intraday trading.

---

## 🎯 Business Problem

An intraday trader has provided an `orders.csv` file containing trading transactions executed across multiple stocks.

The dataset includes trade timestamps, transaction types, stock instruments, product types, quantities, average execution prices, and order statuses.

The business requirement is to develop a Python-based solution that:

- Identifies eligible intraday (MIS) transactions.
- Extracts actual executed quantities from order records.
- Calculates applicable trading charges for every transaction.
- Aggregates trading activity by stock and transaction type.
- Calculates Gross PnL and Net PnL for each stock.
- Generates a structured Excel workbook containing all required analysis.

**Business Goal:** Determine the actual profit or loss generated by each stock after deducting all applicable trading charges.

## 📂 Dataset Description

**Input File:** `orders.csv`

The dataset contains trading order information provided by the client.

| Column | Description |
|---|---|
| Time | Date and time when the trade was placed or executed. |
| Type | Transaction type: Buy or Sell. |
| Instrument | Name or symbol of the traded stock. |
| Product | Trading product type, such as MIS or CNC. |
| Qty. | Quantity in Executed Shares / Total Shares Placed format. |
| Avg. Price | Average execution price of the order. |
| Status | Order status: Completed, Cancelled, or Rejected. |

### Understanding Product Types

| Product | Description |
|---|---|
| MIS | Intraday trading product. Positions are intended to be squared off on the same trading day. |
| CNC | Cash and Carry product, generally used for delivery-based equity trading. |

### Understanding Order Status

| Status | Description | Treatment |
|---|---|---|
| Completed | Order execution completed. | Include executed quantity. |
| Cancelled | Order cancelled, potentially after partial execution. | Include executed quantity, if any. |
| Rejected | Order rejected without valid execution. | Exclude from calculations. |

### Understanding Quantity Format

The `Qty.` column contains two values separated by `/`.

**Example:**

```text
50/100
```

- Executed Shares: 50
- Total Shares Placed: 100

Only the executed quantity should be considered when calculating turnover and transaction charges.

## ⚙️ Project Workflow

The project follows a structured data analytics workflow.

### Step 1: Data Loading and Exploration

- Import the required Python libraries.
- Load the trading dataset using Pandas.
- Examine dataset dimensions, column names, and data types.
- Inspect sample records and identify potential data quality issues.

### Step 2: Data Cleaning and Preprocessing

- Check for missing values and duplicate records.
- Convert columns into appropriate data types.
- Split the quantity column into executed and total placed quantities.
- Handle invalid or inconsistent records.
- Prepare the dataset for financial calculations.

### Step 3: Transaction Filtering

- Identify MIS (Intraday) transactions.
- Exclude CNC transactions from the intraday analysis.
- Exclude rejected orders.
- Retain executed quantities from completed and partially executed cancelled orders.
- Ignore transactions with zero executed quantity.

### Step 4: Turnover Calculation

Calculate the turnover for each individual transaction.

**Formula:**

```text
Turnover = Executed Quantity × Average Price
```

### Step 5: Trading Charges Calculation

Calculate the applicable transaction charges using Zerodha's Equity Intraday (NSE) brokerage structure.

The following charges are considered:

| Charge | Description |
|---|---|
| Brokerage | Brokerage charged on eligible transactions. |
| STT/CTT | Securities Transaction Tax applicable to equity transactions. |
| Exchange Transaction Charges | Charges imposed by the stock exchange. |
| SEBI Charges | Regulatory charges imposed by SEBI. |
| GST | Goods and Services Tax on applicable charge components. |
| Stamp Duty | Applicable government stamp duty on eligible transactions. |

**Total Charges Formula:**

```text
Total Charges =
    Brokerage
  + STT/CTT
  + Exchange Transaction Charges
  + SEBI Charges
  + GST
  + Stamp Duty
```

*The applicable rates, charge bases, and rounding rules should follow the referenced Zerodha Equity Intraday NSE tariff and the project's calculation assumptions.*

### Step 6: Stock-wise and Type-wise Analysis

Group transactions by stock instrument and transaction type (Buy/Sell).

Calculate:

- Total executed quantity.
- Weighted average execution price.
- Total turnover.
- Total brokerage.
- Total STT/CTT.
- Total exchange transaction charges.
- Total SEBI charges.
- Total GST.
- Total stamp duty.
- Total transaction charges.

**Weighted Average Price Formula:**

```text
Weighted Average Price =
    Total Turnover / Total Executed Quantity
```

### Step 7: Gross PnL and Net PnL Calculation

Calculate the trading profitability for each stock by comparing total Buy and Sell turnover.

**Gross PnL Formula:**

```text
Gross PnL = Total Sell Turnover - Total Buy Turnover
```

**Net PnL Formula:**

```text
Net PnL = Gross PnL - Total Charges
```

**Percentage of Charges on Gross PnL:**

```text
Charges Percentage =
    (Total Charges / Gross PnL) × 100
```

*The charges percentage requires special handling when Gross PnL is zero or negative. It should not be interpreted as a conventional profitability percentage in those cases.*

### Step 8: Excel Report Generation

Generate a structured Excel workbook containing three worksheets with the calculated results.

The workbook is designed to provide both detailed transaction-level information and summarized business insights.
